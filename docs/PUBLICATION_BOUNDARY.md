# Publication boundary

The public repository contains the benchmark code, declared model and board
profiles, reproducible protocols, tests, evidence packets, audits, observations,
and paper drafts needed to inspect or repeat the research.

It does not contain credentials, workstation-specific paths, private service
configuration, internal orchestration code, development-session state, or
private operational handoffs. Provider credentials are read from documented
environment variables and are never written to result artifacts.

Historical exploratory evidence is retained only when its protocol and limits
are stated. It must not be pooled with current protocol results or presented as
a current model ranking.
